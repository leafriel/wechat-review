# 微信审核 Skill

让 coding agent 把需求选择、方案审核和关键操作的执行确认发到微信，收到你的回答后继续任务。

## 功能

- **来源清楚**：每道题注明来源对话和任务背景。
- **数字回复**：回复 `15 2`，即可选择第 15 题的第 2 项。
- **并发问答**：多个 agent、多个会话可以同时提问，支持乱序回答。
- **双渠道首答**：宿主支持原生异步提问时，同时发送本地题和微信题，首个有效答案只处理一次。
- **执行确认**：发布、部署、推送、删除数据等关键操作，准备完成后再请求明确同意。

## 安装

需要 Windows 和 Node.js 22+。运行：

```powershell
npx skills add leafriel/wechat-question-skill --skill wechat-review -g
```

按安装器提示选择你的 agent，然后对它说：

> 使用 wechat-review，登录微信审核。

Agent 会检查依赖、展示登录二维码，并引导你扫码和向机器人发送“绑定”。已绑定的用户无需重新登录。

## 使用

在原来的 agent 对话中说：

> 需要我选择方案或确认最终执行时，用 wechat-review 发到微信。

微信会收到类似消息：

```text
微信审核【15】
对话：网站部署方案
任务：个人博客
部署到哪里？
1. 测试环境
2. 生产环境
回复：15 选项编号，例如“15 1”
```

回复 `15 2` 后，agent 收到选择并继续；回复 `15 取消` 可取消本题。

最终执行确认固定为“同意执行／暂不执行／修改方案”，有效期 10 分钟。只有明确选择“同意执行”，才执行题目中说明的操作；超时或错误不会代替你同意。

## 要求与文档

- 适用于能读取 Skill、执行本机脚本并等待结果的 agent；不绑定某个厂商。未逐一验证所有 agent 客户端。
- 本地问题界面与自动匹配由宿主提供；没有原生异步提问能力时使用微信。微信先答后，本地卡片是否自动收回取决于宿主。
- 仅支持 Windows、Node.js 22+ 和已绑定本人的微信私聊文字；电脑、网络及原调用方需要保持运行。
- 用于审核与确认，不提供独立聊天或自动完成通知；用户确认不替代平台权限审批。
